# Telegram-бот для напоминаний

Бот получает текст рекламы, публикует или откладывает **исходный пост и напоминания** в выбранные каналы. Напоминания можно выключить для обычного поста без матча и коэффициента. Для серии бот распознаёт матч и коэффициент, по умолчанию использует загруженные вами фото и берёт тексты напоминаний из пула текстовых шаблонов. Время указывается по Москве. Серии, созданные до этой версии, остаются без автоматической публикации исходной рекламы, чтобы не продублировать рекламу, уже подготовленную в Posted.

## Запуск

Нужен Node.js 22 или новее. После копирования проекта выполните `npm install`.

Для постоянной работы на виртуальной машине Yandex Cloud см. [инструкцию развёртывания](deploy/yandex/README.md).

1. Создайте своего бота через [@BotFather](https://t.me/BotFather) командой `/newbot`. BotFather выдаст `BOT_TOKEN` — секретный ключ для запросов к Telegram. Не отправляйте его в переписке и не публикуйте.
2. Добавьте бота администратором нужных каналов с правами публиковать и удалять сообщения.
3. Скопируйте `.env.example` в `.env` и впишите только `BOT_TOKEN`. Остановите основной процесс бота, если он уже работает, затем выполните `npm run setup`. Напишите своему боту `/start` и опубликуйте по одному **новому** сообщению в каждом канале. Команда покажет ваш числовой `OWNER_ID` и ID каждого канала; нажмите Ctrl+C после получения всех ID. Старые сообщения бот через этот способ не прочитает.
4. Заполните остальные поля `.env`: `OWNER_ID` — ID одного или нескольких пользователей через запятую (`123456789,987654321`); `NETWORK_1` и `NETWORK_2` — ID каналов каждой сетки через запятую. Для теста достаточно одного канала в любой сетке. Для закрытых каналов нужны числовые ID вида `-100...`, ссылка-приглашение сюда не подходит. Ключ OpenAI боту больше не нужен.
5. Выполните `npm run verify`: команда проверит токен, доступ к каналам и права бота, не выводя токен. Затем запустите `npm start`. Компьютер должен оставаться включённым и подключённым к интернету. Для круглосуточной работы позднее можно перенести эту же папку на VPS.

Пример заполнения после определения ID:

```text
BOT_TOKEN=123456789:секретный-токен-из-BotFather
OWNER_ID=987654321
NETWORK_1=-1001111111111,-1002222222222
NETWORK_2=-1003333333333,-1004444444444,-1005555555555,-1006666666666,-1007777777777
```

Бот отвечает пользователям с правами администратора хотя бы в одном подключённом канале. `OWNER_ID` нужен для начальной настройки и служебных уведомлений, но не ограничивает список пользователей. Черновики и шаги редактирования разделены по пользователям. При открытии контент-плана сначала выбирается сетка; в ней видны только реклама и напоминания, созданные этим ботом в каналах, где пользователь администратор, независимо от автора. Скопированная серия остаётся связанной: изменение поста или напоминания из доступного канала обновляет все копии серии во всех каналах. Настройки сохраняются в `data.json`; сделайте резервную копию этого файла перед переносом на сервер. Не запускайте два экземпляра бота одновременно.

После каждой успешной публикации рекламы или напоминания бот отправляет **первому ID из `OWNER_ID`** уведомление по сетке со списком каналов, московским временем и кнопками перехода к вышедшим сообщениям. Для закрытого канала ссылка откроется у администратора, имеющего к нему доступ. Когда выходит следующий пост или напоминание, бот удаляет прежние уведомления о публикации из личного чата. Уведомления двух сеток об одном времени выхода остаются вместе. Предупреждения об ошибках не удаляются. Уведомления не отправляются о старых публикациях при перезапуске. Если Telegram временно недоступен, бот повторит отправку уведомления, не публикуя пост повторно.

## Работа с постом

При запуске через `npm start` бот в Windows удерживает систему от автоматического перехода в сон. Экран при этом может выключаться обычным образом. После остановки бота запрос на бодрствование снимается; настройки электропитания Windows бот не изменяет.

1. Пришлите текст рекламы или фото с подписью. Если фото отдельно, нажмите «Прикрепить медиа» и пришлите его: в превью изображение появится после текста внутри цитаты того же сообщения. На шаге прикрепления можно вернуться к посту без фото. Это фото не используется для напоминаний.
2. Нажмите «Кнопка» и пришлите строку `СМОТРЕТЬ ПРОГНОЗ - https://t.me/ваша_ссылка` без квадратных скобок. Кнопка сохранится сразу. Выберите сетку или отдельные каналы через «Копировать в каналы». Для обычного поста без серии нажмите «Напоминания: включены», чтобы выключить их. В этом режиме матч, коэффициент, кнопка и конец размещения необязательны.
3. Нажмите «Отложить» и укажите **время выхода рекламы через нашего бота**, затем конец её размещения. Форматы: `19` (19:00), `1928` (19:28), `25.09 18:00`, `завтра 19`. Бот публикует рекламу в выбранных каналах. Первое автоматическое напоминание обычно выходит через 30 минут после рекламы. Следующие идут с шагом не менее 30 минут и не раньше удаления предыдущего. Если у рекламы задан таймер удаления, её удаление становится пределом серии: для поста в 16:00 с удалением через 40 минут и напоминания с удалением через 20 минут выйдет одно напоминание в 16:20; оба сообщения удалятся в 16:40. Для рекламы 15:00–18:00 без таймера удаления поста и с таймером напоминания 2 ч 30 мин выйдет одно в 15:30. Если удаление напоминаний отключено, сохраняется шаг в 30 минут. В редакторе отдельную напоминалку можно перенести на любое будущее время после выхода рекламы, в том числе раньше первого автоматического слота или после конца размещения.
4. Исходный пост по умолчанию не удаляется. Кнопка «Удаление поста» задаёт его таймер; `нет` отключает удаление. Таймер удаления каждого напоминания по умолчанию 30 минут, но его тоже можно изменить или отключить словом `нет`. В меню есть быстрые варианты 15 и 30 минут, 1 час, 1 час 30 минут, 2, 6 и 10 часов. Можно сразу отправить своё время, например `0 15`, `1` или `1 30`: дополнительную кнопку нажимать не нужно. Допустим любой интервал от 1 минуты до 47 часов 59 минут. Служебные запросы бот удаляет после успешного ответа; короткие подтверждения исчезают через 20 секунд.
5. Нажмите «Превью»: бот покажет текст рекламы с прикреплённым фото в цитате (если есть), затем **каждое напоминание** с собственной картинкой в цитате под текстом. Затем нажмите «Отложить» ещё раз для сохранения серии. «Опубликовать сейчас» отправит основной пост немедленно; если напоминания включены, сначала задайте конец размещения и проверьте превью, после чего они выйдут по рассчитанному расписанию. Обычный пост без напоминаний можно опубликовать сразу без превью. Кнопка «Отменить создание» удаляет черновик без отправки в каналы. При ошибке кнопка «Назад к черновику» сохраняет введённые настройки. После откладывания, публикации или отмены бот удаляет из личного чата и служебный текст, и сами сообщения предпросмотра поста и напоминаний.

В редакторе кнопка «🖼 Картинка» позволяет загрузить свои фото или выбрать поиск в интернете. Свои фото выбраны по умолчанию. Пришлите от одного до числа напоминаний фото по одному или альбомом, затем нажмите «Готово» и «Превью». Если фото меньше, чем напоминаний, они повторятся по порядку. Ранее подготовленные изображения отложенных серий сохраняются; новых изображений через OpenAI бот не создаёт.

Если после интернет-поиска картинки в превью не подходят, нажмите «🔄 Перенайти картинки» в черновике. Бот пропустит все уже показанные в этом черновике ссылки и заново покажет напоминания. Если других подходящих изображений недостаточно, старый предпросмотр и подготовленные фото сохранятся; можно загрузить свои фото. Поиск различает «Англию» и клуб New England Revolution, понимает «Чехия»/Czechia/Czech Republic и не берёт женские или молодёжные турниры для поста без такого указания.

Интернет-режим сначала ищет изображения **первого матча** в Wikimedia Commons. Названия клубов ищутся на русском и английском независимо от языка поста: для известных команд используется встроенный словарь, для остальных бот пробует найти название на другом языке через Википедию и дополнительно ищет по транслитерации. Если нужного числа фото не набралось, бот ищет недостающие по следующему матчу, учитывая его собственный вид спорта; так же работает и для остальных матчей в посте. Поиск учитывает вид спорта и турнир из текста рекламы: КХЛ, НХЛ, Лигу наций, Серию А, Ла Лигу и другие распространённые футбольные соревнования. Для известных хоккейных команд КХЛ или НХЛ определяется также по названию клуба. Ограничения по году снимка нет. Одиночные логотипы, гербы, флаги, пустые арены и фотографии другого вида спорта отсеиваются. Каждый найденный кадр бот проверяет локальным детектором людей OpenCV: изображение никуда дополнительно не отправляется, а результат проверки кешируется. Вид спорта и турнир проверяются по названию и описанию файла, поэтому предпросмотр остаётся обязательным. Если подходящих фото не хватает и заданы `YANDEX_SEARCH_API_KEY` и `YANDEX_FOLDER_ID`, бот ищет дополнительные варианты через официальный API Яндекс.Картинок. Каждая найденная картинка используется не более двух раз; если фото недостаточно, можно загрузить свои в том же черновике. Загруженные фото и результаты поиска сохраняются в `internet-assets/`.

Встроенный словарь `club-catalog.js` содержит 32 клуба НХЛ и участников сезона 2026/27 четырёх высших футбольных лиг: АПЛ (20), Бундеслиги (18), Ла Лиги (20) и Лиги 1 (18). Составы сверены с официальными списками [НХЛ](https://www.nhl.com/info/teams/), [АПЛ](https://www.premierleague.com/en/news/4725666/all-you-need-to-know-about-the-20-premier-league-stadiums), [Бундеслиги](https://www.bundesliga.com/de/bundesliga/clubs), [Ла Лиги](https://www.laliga.com/laliga-easports/clubes) и [Лиги 1](https://ligue1.com/en/competitions/ligue1mcdonalds/standings?season=2026). После смены сезона список участников нужно обновить.

Для локальной проверки людей нужен Python 3 с пакетами из `requirements-vision.txt` и модель в `detector-models/`. Установите пакеты командой `python -m pip install -r requirements-vision.txt`. Если Python не находится в PATH, задайте полный путь в `PERSON_DETECTOR_PYTHON` в `.env`. На текущем компьютере бот использует Python из Codex и установленные в `.cv-deps` пакеты. Модель взята из [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/person_detection_mediapipe) (Apache 2.0).

Названия команд выводятся заглавными белыми буквами с тёмной обводкой. Для длинных названий бот переносит слово на две строки и подбирает размер по свободной области. Используется включённый в проект шрифт Russo One; его лицензия находится в `fonts/OFL.txt`.

Старая команда `/schedule` также работает, если удобнее ввести все параметры одной строкой:

```text
/schedule 2026-09-24 15:00 | 2026-09-24 18:00 | 30 | https://t.me/your_channel | ЗАБРАТЬ ПРОГНОЗ
```

Первое напоминание выйдет в 15:30, затем каждые 30 минут, последнее в 17:30. Число `30` означает удалить **каждое** напоминание через 30 минут после его выхода.

`/plan` открывает контент-план по московским дням: отдельная строка для рекламы и каждого напоминания, с таймером удаления. Можно листать дни и развернуть календарь. При открытии строки бот показывает **сам пост или напоминание** в том виде, в каком оно выйдет, а затем сведения и кнопки управления. Кнопка «Дублировать в другую сетку» копирует только открытую запись: выберите сетку, время и таймер удаления, затем отложите копию или опубликуйте её сразу. Копия независима от исходной серии; отдельная копия напоминания не создаёт рекламного поста в контент-плане. После создания копии открывается план выбранной сетки. В карточке отложенного поста есть «Опубликовать сейчас»: пост выходит сразу, а ожидающие напоминания сдвигаются вместе с ним. Возврат из карточки или редактора сохраняет выбранный день и страницу списка. У рекламного поста есть кнопка «Удаление поста»: её можно использовать до и после публикации, и новый таймер применяется ко всем копиям поста в каналах. Если новое время удаления уже прошло, опубликованный пост будет удалён при ближайшей проверке очереди. У каждого напоминания есть собственные кнопки «Изменить это напоминание» и «Удалить эту напоминалку»: можно заменить текст, фото, кнопку, время выхода до публикации и таймер удаления либо отменить только эту запись. Изменение и удаление применяются к этому напоминанию во всех выбранных каналах и не затрагивают рекламу и остальные записи серии. Удаление всей серии требует отдельного подтверждения в карточке рекламы; будущие публикации отменяются, вышедшие удаляются из каналов. После начала серии нельзя менять время рекламы или набор каналов.

Для обычной работы ручной ввод матча и коэффициента не нужен: они берутся из текста рекламы. Если распознавание не удалось, доступны команды `/matches` и `/odds`.

## Пул шаблонов

Изначально есть 24 примера для проверки. Для вашего готового пула отправьте `/cleartemplates`, затем `/importchannel` и перешлите из отдельного канала 20–40 готовых напоминаний. Бот распознаёт матчи и коэффициент в каждом и подставляет данные новой рекламы. Сохраняются жирный, курсив и другие выделения, ссылки и премиум-эмодзи внутри текста. После пересылки отправьте `/done`. Через `/addtemplate` можно добавить готовую напоминалку без служебных `{matches}` и `{odds}`. Если матч или коэффициент не распознаны, текст сохраняется как есть; при желании места подстановки можно указать вручную. Старую историю канала бот сам прочитать не может: существующие посты нужно переслать ему либо экспортировать.

Для каждой новой рекламы бот случайно выбирает шаблоны из пула и сохраняет выбор после предпросмотра. Для футбольной, хоккейной, теннисной и баскетбольной рекламы подходят шаблоны своего вида спорта и нейтральные. В строках матчей бот ставит ⚽️, 🏒, 🎾 или 🏀; в смешанном посте значок подбирается отдельно для каждого матча. Названия команд в строках матчей не считаются указанием вида спорта. До шести напоминаний все тексты должны быть разными; в более длинной серии один текст может повториться максимум дважды. Проверяется итоговый текст после подстановки матча и коэффициента. Кнопка «📚 Шаблоны текстов» или `/templates` открывает список с навигацией по страницам: нажмите на шаблон, чтобы прочитать исходный текст с оформлением, изменить его, удалить после подтверждения или добавить новый. После «Изменить» пришлите новую готовую напоминалку. Правка и удаление влияют только на новые серии; уже отложенные напоминания сохраняют прежний текст. Также можно импортировать `.txt` через `/importtemplates`: разделитель между шаблонами — отдельная строка `---`. В `.txt` по-прежнему можно вручную указать `{matches}`, `{odds}` и `{sport}`. `/defaulttemplates` вернёт примеры.

Пример:

```text
🎯 **БЕСПЛАТНЫЙ ПРОГНОЗ** 🎯
🔝 **Коэффициент — {odds}**

{matches}

⬇️ **ПРОГНОЗ В КНОПКЕ** ⬇️
---
⚡ **ПРОГНОЗ НА СЕГОДНЯ**

{matches}

📊 **{odds}**
👇 Забирайте по кнопке
```

Если разных итоговых текстов не хватает с учётом ограничения на повторы, бот попросит пополнить пул. Готовая напоминалка может содержать до 4000 символов.

## Ограничения

- Премиум-эмодзи из присланной напоминалки сохраняются как Telegram `custom_emoji` вместе с остальным оформлением. Чтобы бот мог публиковать их **в каналах**, Telegram требует дополнительный username бота, купленный на Fragment. Premium-подписка владельца позволяет отправлять их ботом в личные чаты, группы и супергруппы, но сама по себе не даёт такого права для каналов. Поэтому удачное превью в личном чате ещё не гарантирует публикацию в канале. Если Telegram отклонит премиум-эмодзи, бот покажет ошибку и не станет незаметно заменять их обычными.
- При поиске в интернете используется первый распознанный матч. Поиск не проверяет права на публикацию найденного изображения.
- Telegram Bot API разрешает удалять сообщения только пока им меньше 48 часов. Бот принимает таймер до 47 часов 59 минут; сообщение, вышедшее раньше этого предела, Telegram удалить не даст.
- При обрыве связи бот повторит публикацию. Если процесс прервётся ровно во время отправки и результат неизвестен, бот пометит публикацию как `uncertain` и сообщит владельцу, чтобы не создать дубликат автоматически.
- Перед реальным использованием проверьте одну короткую серию на тестовом канале, включая кнопку и удаление.
