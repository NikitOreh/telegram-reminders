# Подключение Premium-аккаунта к Posted: этап 1

Сейчас реализованы только вход в аккаунт, проверка Premium и чтение последнего меню `@posted`. Инструмент не отправляет сообщения, не нажимает кнопки, не публикует и не изменяет отложенные посты. Рабочий `bot.js` его не импортирует. Проверка передачи фото-цитаты и настройка расписания будут реализованы после подключения аккаунта и изучения фактического интерфейса Posted.

## Подготовка в Telegram

Войдите в отдельный Premium-аккаунт в обычном приложении Telegram. Добавьте его администратором тестового канала. Откройте именно `https://t.me/posted`, нажмите «Старт» и подключите тестовый канал через меню сервиса. Выдайте боту сервиса права, которые нужны ему для публикации и удаления. Не выбирайте рабочие каналы для первого теста.

## Настройки приложения

1. Получите свои `api_id` и `api_hash` на `https://my.telegram.org` → **API development tools**. Это параметры Telegram-приложения, а не токен BotFather. В форме достаточно заполнить App title и Short name; выберите подходящую платформу.
2. Скопируйте `integrations/posted/.env.example` в `integrations/posted/.env` и заполните `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`. Файл `.env` игнорируется Git. Секреты не нужно присылать в чат.
3. Оставьте `POSTED_PROFILE=owner` для первого аккаунта. Для другого аккаунта используйте отдельное имя профиля. Один профиль привязывается к одному пользовательскому аккаунту и одному боту сервиса.

## Локальный вход

Из папки проекта выполните:

```powershell
npm run posted:setup
npm run posted:schema
npm run posted:login
npm run posted:check
npm run posted:inspect
```

`setup` устанавливает Telethon 1.45.0 в `.posted-deps/`, отдельно от зависимостей рабочего бота и детектора фото. При необходимости укажите путь к Python 3 в переменной `POSTED_PYTHON`. На текущем компьютере launcher умеет находить Python из локального runtime Codex.

`login` запускайте в своём интерактивном терминале. Введите номер отдельного аккаунта, код Telegram и пароль двухэтапной проверки, если он установлен. Эти значения вводятся скрыто. Не используйте командную строку с секретами в аргументах. Уже авторизованный профиль не запрашивает вход повторно.

`check` не запускает новую авторизацию: проверяет существующую сессию, Premium и бота Posted. `inspect` читает только последние сообщения в диалоге с Posted. В консоли показываются названия кнопок; текст последнего ответа хранится в закрытом локальном отчёте.

Файл сессии `private/posted/owner/account.session` предоставляет доступ к аккаунту. Он и все отчёты исключены из Git; на Linux папка имеет права 0700, файлы — 0600. Никогда не прикладывайте папку `private/` к репозиторию. В Telegram авторизация отображается как **Reminders Posted Connector**; отозвать её можно в «Настройки → Устройства». Никаких строк сессии инструмент не печатает. После аварийного завершения блокировка профиля освобождается операционной системой.

Локальный вход нужен для первого теста. Постоянную работу перенесём на сервер только после подтверждения схемы; для каждого будущего пользователя предусматривается отдельный профиль. На этом этапе аккаунты клиентов ещё не подключаются через интерфейс нашего бота.

## Проверка разработки

```powershell
node integrations/posted/launcher.js test
npm test
```

Python-тесты используют подставной клиент и не обращаются к Telegram. Команда `schema` проверяет установленную библиотеку без входа и сети. Успешная проверка схемы не доказывает совместимость фото-цитаты с Posted.

## Следующая проверка

На тестовом канале нужно подтвердить всю цепочку: исходный текст с `custom_emoji` → фото внутри цитаты после текста → обычная URL-кнопка → постановка в Posted → фактическая публикация → удаление по таймеру. Потеря премиум-эмодзи или замена фото-цитаты обычным фото считается провалом теста. До его прохождения внешняя публикация не подключается к очереди, а старые серии продолжают обслуживаться прежним механизмом.

Документация: [Telegram API ID](https://core.telegram.org/api/obtaining_api_id), [Telethon: сессии](https://docs.telethon.dev/en/stable/concepts/sessions.html), [формат rich-сообщений](https://core.telegram.org/bots/api#rich-messages).
